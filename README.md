## Eesmärk

Portfoolio eesmärk on dokumenteerida minu arengut andmeanalüütikuna ning koondada DACA programmi käigus valminud individuaalsed tööd ühte GitHubi repositooriumi.

Tööde käigus olen tegelenud:

- andmete kvaliteedi kontrollimisega;
- andmete puhastamise ja ettevalmistamisega;
- SQL-päringute koostamisega;
- erinevate tabelite ühendamisega;
- andmete agregeerimise ja analüüsimisega;
- tulemuste visualiseerimisega Power BI-s;
- interaktiivsete dashboard’ide loomisega;
- andmeloo ja juhtide kokkuvõtte koostamisega;
- dashboard’i avaldamise ja mobiilivaate seadistamisega.

## Portfoolio sisu

Iga nädala kaust sisaldab vastava teema README dokumentatsiooni ning võimalusel ka töö käigus loodud faile, päringuid, ekraanipilte või dashboard’e.

Portfoolio täieneb DACA programmi jooksul nädalate kaupa.
